# Source Onboarding Checklist

- first-party documentation identified
- license/terms recorded
- persistence rights determined
- redistribution/attribution determined
- asset rights separated
- acquisition mode approved
- robots/access restrictions reviewed where relevant
- schedule/rate budget documented
- source policy committed
- fixtures captured legally
- parser/schema-drift tests
- checkpoint/restart tests
- malformed payload tests
- field authority mapping
- sample data-quality audit
- Administrator enable/disable control
- source health dashboard
