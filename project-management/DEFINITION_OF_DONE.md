# Definition of Done

A change is done only when:
- acceptance criteria pass;
- code/docs reviewed;
- tests added and passing;
- migration tested if relevant;
- source/security implications resolved;
- observability added for operational behavior;
- OpenAPI updated for public contract;
- changelog updated when user-visible;
- no unresolved critical/high shipped vulnerability;
- reconciliation benchmark passes when applicable;
- issue/ADR linked.
