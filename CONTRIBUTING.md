# Contributing to BookDB

BookDB welcomes code, documentation, connector, test, and data-quality contributions.

Before contributing:
1. read `agent-kit/AGENTS.md`;
2. read architecture/source policy documents;
3. open/link an issue;
4. do not add a metadata source without source-policy review;
5. do not submit user-library scraping;
6. do not bypass Administrator publication rules.

Pull requests must include tests and documentation appropriate to the change.
