# ADR-0001 — License BookDB Server AGPL, SDKs Apache-2.0

Status: Accepted

## Decision
- BookDB server/WebUI/workers: AGPL-3.0-or-later.
- Official API schemas/client SDKs: Apache-2.0.
- Documentation: CC BY-SA 4.0 recommendation.

## Rationale
BookDB is network-server software and the owner requires it to remain FOSS. Strong network copyleft protects hosted modifications while permissive SDK licensing encourages broad API adoption.
