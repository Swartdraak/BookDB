# Security Policy

Report suspected vulnerabilities privately through GitHub Security Advisories or the security contact configured by project maintainers. Do not publish exploitable details in ordinary issues.

Security-sensitive areas include:
- authentication/OIDC;
- source connectors/SSRF;
- parsers/decompression;
- user proposals/XSS;
- API keys;
- distributed messaging;
- object storage;
- dependency/supply chain.
