# Skill — Durable Event Contract

1. Define business event/job purpose.
2. Define schema version.
3. Define idempotency key.
4. Define delivery assumptions (at-least-once).
5. Define ACK point.
6. Define retries/dead-letter.
7. Define tracing metadata.
8. Define producer/consumer ownership.
9. Add compatibility tests.
10. Require architecture review for new event family.
