# Scheduling Documentation / Roadmap

## M0 — Repository and licenses
Monorepo, CI, AGPL server licensing, Apache SDK boundary, Dev Container, conventions.

## M1 — Canonical schema and auth skeleton
Domain model, claims/provenance, proposals, audit, local/OIDC framework.

## M2 — Distributed platform
PostgreSQL 18 baseline/HA contract, NATS JetStream, outbox, Valkey cache, OpenSearch, S3 abstraction.

## M3 — Source governance and scheduler
Policy registry, scheduled/manual sync, connector SDK, checkpoints, quarantine.

## M4 — Identity and reconciliation
Normalization, candidate resolution, contradiction gates, merge/split, canonical publication.

## M5 — Bootstrap and quality
Open Library/Wikidata ingestion, full-scale benchmark, data-quality dashboard.

## M6 — API/search/SDK
OpenAPI, search, exact resolution, changes, Apache-licensed SDK.

## M7 — Public and Admin WebUI
Catalog pages, proposals, Administrator approval, evidence/merge/split, source controls.

## M8 — Assets and expanded sources
S3/image pipeline, rights controls, additional approved metadata sources.

## M9 — PVR integrations
Audiobookshelf adapter, Calibre integration, generic client guidance.

## M10 — HA/security/performance hardening
Failure tests, backup/restore, load, security, rolling upgrade.

## M11 — v1.0 RC/GA
Source-policy review, migration freeze, release checklist, signed artifacts, documentation audit.

Each milestone requires test evidence, risk review, documentation and PM acceptance.
