# User Documentation

Users can:
- search BookDB by title, person, series, ISBN and supported IDs;
- browse works and specific editions;
- distinguish ebook/audiobook editions and translations;
- inspect permitted provenance;
- submit proposals for missing or incorrect metadata.

## Proposals

A proposal is not a direct edit.

After submission:
- BookDB validates it;
- it may be triaged;
- an Administrator reviews it;
- only Administrator approval can publish user-provided information.

Users can view proposal status and any request for more information.
