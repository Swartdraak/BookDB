# End-User Guide

## Search

Use global search or paste an ISBN/known identifier.

## Entity types

- Work — the intellectual creation
- Expression — translation/revision/audio realization
- Edition — a specific published manifestation
- Person — author/narrator/editor/etc.
- Series — sequence/group relationship

## Suggesting changes

Use **Propose correction** or **Add missing record**.

Your proposal does not change public metadata immediately. An Administrator must approve all user-provided additions/corrections before publication.

## API

Where enabled, create a scoped API key in account settings and follow the OpenAPI-backed client documentation.
