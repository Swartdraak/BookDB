# License Files Required During Repository Bootstrap

The implementation repository must contain:

- root `LICENSE`: complete, unmodified GNU AGPLv3 text; BookDB server packages declare `AGPL-3.0-or-later`;
- `LICENSES/Apache-2.0.txt`: complete Apache License 2.0 for separately packaged official SDKs/API clients;
- a documentation license notice for CC BY-SA 4.0 if that recommendation is adopted.

Do not hand-edit standard license texts. Copy them verbatim from the authoritative license steward and track SPDX identifiers.
